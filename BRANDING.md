## Uses that do not require separate permission

You may:

- use the QuixShare name and an unmodified logo to refer truthfully to this
  project, including in reviews, screenshots, links, and compatibility notes;
- redistribute the unmodified logos with an unmodified official QuixShare
  source or binary release; and
- include the unmodified logos in a materially faithful package of QuixShare,
  provided an unofficial package is clearly identified as unofficial, links to
  the canonical repository, and does not imply endorsement by xntsO.

Resizing or lossless format conversion for those uses is permitted when the
logo's appearance is not otherwise changed.

## Uses that require permission

Written permission from xntsO is required to:

- use the QuixShare name or logos for a modified fork or a different product;
- alter the artwork beyond technical resizing or format conversion;
- use the marks on merchandise or as commercial branding; or
- register a confusingly similar project name, account, domain, application
  identifier, or mark.

Modified distributions and forks should use a distinct name, application ID,
and artwork. They may state factually that they are based on QuixShare. This
policy does not limit rights granted for the source code by Apache-2.0 or
ordinary truthful references permitted by applicable law.
